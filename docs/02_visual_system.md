# Visual System

## Design Direction

The Voxa visual system combines precise feedback with soft presentation.

Principles:
- modern and premium, but not luxurious in a distant way
- calm and emotionally safe
- readable and data-capable
- clearly branded without stereotype-heavy gender coding

## Logo Direction

Chosen direction: **Voxa Pulse**

The logo should be based on a stylized **V** that transitions into a soft pitch wave.

The symbol should communicate:
- voice
- movement
- measurement
- progress

It should work as:
- app icon
- splash logo
- wordmark lockup
- monochrome mark

## Usage Recommendations

- Use **Violet** as the primary brand signal
- Use **Teal** as a fresh secondary accent
- Use **Night / Indigo** as the structural base
- Keep semantic training colors mostly inside practice and analysis views

## Typography

Recommended primary typeface: **Manrope**

Why:
- soft enough for a sensitive product
- modern enough for a technical app
- highly readable in UI
- works well in both English and German

Alternatives:
- Inter
- Plus Jakarta Sans

### Type Hierarchy

- Display / Hero – bold, spacious
- Section headers – strong but calm
- Body – readable, open line height
- Data labels – compact and clear
- Metric values – large and prominent

## Shape Language

- rounded corners
- clean cards
- minimal hard dividers
- curved charts and gauges when appropriate
- medium to large radii

Suggested radius range:
- cards: 20–24
- buttons: 16–20
- sheets / dialogs: 24–28

## Imagery and Illustration

Prefer:
- gradients
- abstract curves
- waveform-inspired graphics
- soft glows used sparingly
- calm editorial illustrations or abstract motion-inspired visuals

Avoid:
- generic microphone icons as dominant motif
- cliché pink-vs-blue visuals
- overly medical visuals
- cartoon-heavy or childish illustrations
