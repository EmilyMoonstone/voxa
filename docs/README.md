# Voxa Design Concept

This folder contains the current product and design foundation for **Voxa**, a voice training app for trans* people.

## Files

- `01_brand_foundation.md` – brand purpose, tone, audience, positioning
- `02_visual_system.md` – logo direction, color palette, typography, imagery
- `03_ui_ux_principles.md` – UI principles, key screens, accessibility, interaction patterns
- `04_flutter_design_tokens.md` – suggested design tokens for Flutter / Material 3
- `features.md` – feature scope for MVP and future iterations
- `roadmap.md` – phased product roadmap
- `architecture.md` – app architecture, modules, data flow, storage and technical decisions
- `voice.md` - Dieses Dokument bündelt die wissenschaftliche Basis für **Voxa**, einen Voice-Trainer mit Fokus auf gender-affirmende Stimmarbeit. Es dient als fachliche Grundlage für Produktentscheidungen, Zielbereiche, Feedback-Logik und Sicherheitshinweise in der App.

## Brand Summary

**Voxa** is a calm, modern and affirming voice training app. The product should support self-determined voice exploration and practice, not enforce a narrow norm.

Core color direction:
- **Violet** as primary brand color
- **Teal** as fresh counter-accent
- **Night / Indigo** as calm foundation

## Product Summary

Initial languages:
- German
- English

Core MVP areas:
- Goal setting
- Practice mode with live pitch feedback
- Record & analyse
- History
- Settings

## Current Design Direction

- Clear data, soft presentation
- Large central live feedback elements
- Inclusive, non-clinical tone
- Strong accessibility baseline
- Material 3 foundation with custom Voxa branding
